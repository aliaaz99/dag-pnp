# DAG-PnP

DAG-PnP is a plug-and-play method for causal discovery from observational data. It combines gradient updates for a linear structural equation model with a DAGMA acyclicity penalty and a learned diffusion prior over weighted directed acyclic graphs. A barrier-aware step size and projection help keep estimates within the feasible region. This repository provides the code, pretrained diffusion models, input data and result summaries for the experiments described in the paper.

## Please cite this paper

If you use this code or its results, please cite:

Nicolas Zilberstein, Ali Azizpour, Gonzalo Mateos, and Santiago Segarra, “DAG-PnP: Plug-and-Play Causal Discovery with Diffusion Priors.”

| Script | Experiment |
|---|---|
| `table1.py` | Synthetic ER4/SF4 benchmarks, d=20 and d=50 |
| `table2.py` | Barrier step size and projection |
| `table3.py` | Sample-size sensitivity |
| `table4.py` | Sachs protein network |

## Setup

The table-printing scripts need Python 3.7 or newer and no third-party packages. To run the optimization experiments, create a Python 3.7.12 environment and install the pinned dependencies:

```bash
conda create -n dag-pnp python=3.7.12
conda activate dag-pnp
python -m pip install -r requirements.txt
```

## Display results

```bash
python table1.py
python table2.py
python table3.py
python table4.py
```

These commands print the **bundled precomputed results**. Export with
`--format csv` or `--format latex`. Paths are resolved relative to the repository,
so the scripts can be invoked from any directory.

## Run experiments

With the setup above, run the experiments using:

```bash
python rerun.py 1 --output outputs/table1
python rerun.py 2 --output outputs/table2
python rerun.py 3 --output outputs/table3
python rerun.py 4 --output outputs/table4
```

Display newly computed results using the corresponding output directory:

```bash
python table1.py --results outputs/table1
python table2.py --results outputs/table2
python table3.py --results outputs/table3
python table4.py --results outputs/table4
```

Defaults are 10 seeds, 1000 iterations, CPU execution and one thread. Options
include `--seeds`, `--iterations`, `--torch-seed`, `--threads` and
`--checkpoint SF|ER`. Each run saves seed-level CSVs, a console log and its
settings in a new output directory. Existing directories are not overwritten.
For a quick execution check:

```bash
python rerun.py 3 --seeds 1 --iterations 20 --output outputs/quick
python table3.py --results outputs/quick
```

The supplied checkpoints are used for inference; diffusion training is not
required or included. New stochastic runs may vary from the bundled summaries.
Greedy-BIC at d=50 is the slowest component. Table 1's time column uses ER4 runs.
Sachs uses the supplied dataset's 600 rows with `INT=8`, across 11 variables.
Standard deviations use the population convention (`ddof=0`).

## Layout

- `src/`: optimization, experiment and diffusion inference code.
- `checkpoints/`: pretrained SF and ER models.
- `data/`: Sachs input data; synthetic data are generated by the scripts.
- `configs/`: experiment settings.
- `results/`: precomputed table summaries.
- `rerun.py`: experiment launcher with recorded random seeds and settings.
- `table1.py`–`table4.py`: table rendering and result aggregation.
